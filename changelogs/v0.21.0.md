## v0.21.0 · 管理界面搬进 root 管理器

知言不再需要单独安装「知言」应用：管理页随模块一起装好，在 KernelSU / APatch 的模块列表里点知言即可打开。

### 变化

- **模块网页界面**（`webroot/`）：原应用首页与设置页的全部内容——状态卡与连接链路、服务地址与令牌、端口与令牌设置（含生成新令牌）、模块开关、保活看守、打开 / 重新启动微信、后台运行设置、检查更新与一键更新、诊断报告。冻结时沿用冻结前状态等判定规则与原应用一致。
- **`ctl.sh`**：页面的每个 root 动作都是它的一条子命令（`probe`、`write-conf`、`set-enabled`、`guard`、`wakelock`、`restart`、`update-install` …），终端里也能直接用，Magisk 用户没有网页界面时可以用它。
- **唤醒锁开关搬到管理页**：常驻通知上不再有「获取 / 释放唤醒锁」按钮（它原本是发给应用的广播，没有应用就没人接）。
- **更新**：打开管理页时检查（6 小时内不重复，可关闭），下载后核对 SHA-256，交给 `ksud` / `apd` / `magisk` 安装，装好后可在页首「立即重启」。模块列表里的更新提示照旧。

### 升级

刷入新模块并重启手机后，可以卸载旧的「知言」应用（`com.satori.wx`）。端口与令牌配置原样保留。
